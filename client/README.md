# client

Next.js 16 frontend for the booking service. See the root `CLAUDE.md` for
project-wide conventions.

## API types

`src/lib/api/schema.d.ts` is generated by `openapi-typescript` from the
backend's OpenAPI spec — do not edit it by hand. After changing any backend
route/schema, regenerate it with the backend running on `:3000`:

```bash
pnpm gen:api
```
